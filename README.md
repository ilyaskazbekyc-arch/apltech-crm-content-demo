# APLTech CRM — интерактивное демо

Отдельный демонстрационный проект в оформлении APLTech CRM: 20 товаров, листинг и PDP, запросы Content AplTech, SLA, KPI и аналитика. Категорий и фильтров нет.

**Этот проект не подключается к основной CRM.** Все товары, сотрудники и запросы — демонстрационные. Внешних API и авторизации производственной админки нет. Состояние сохраняется в localStorage этого браузера и синхронизируется между его вкладками. Между устройствами данные не общие.

## Запуск

```sh
npm ci
npm run dev
```

```sh
npm test
npm run build
```

## Сценарий просмотра

1. В роли менеджера открыть товар и отправить запрос в Content AplTech.
2. Выбрать роль специалиста, отдельно подтвердить уведомление и взять запрос.
3. Изменить карточку, завершить запрос и открыть аналитику: результат начислится один раз, с ×1,5 при обоих SLA.
4. Создать список товаров: исполнитель задаёт общий срок; таймеров строк нет.
5. Вернуть запрос менеджеру с вопросом и новым сроком. Ответ менеджера вернёт тот же ID в свободную очередь.
6. В роли руководителя менять приоритеты, веса и правила. Открытые запросы наследуют приоритет; прошлые WU сохраняют снимок расчёта.

Демо-часы начинаются 08.10.2026 в 10:00 (UTC+5); кнопки +1/+5 минут и +1 час помогают проверить SLA. Рабочий календарь 5/2, 09:00–18:00; праздники настраиваются. Одной карточке дают 5/10 минут после взятия, команде 2 минуты на ответственного. Штраф SLA ограничен 1 п.п. на запрос; предварительное уведомление с причиной снимает только штраф исполнения без лимита задержки в пилоте. Бонус проверяется по исходному сроку. Отметка ошибки немедленно списывает качество последнего автора контента; есть оспаривание и решение руководителя.

Подробные решения и отдельно обозначенные предложения пилота — в `SPECIFICATION.md`.
